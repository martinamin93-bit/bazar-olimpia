# Bazar Olímpia

Site de uma loja virtual institucional feito para a Situação de Aprendizagem 01.

## Páginas

- index.html - página inicial com as categorias
- produtos.html - produtos e tabela de frete
- contato.html - formulário de contato

## Imagens

As imagens ficam na pasta img/ em formato SVG (ilustrações vetoriais leves, que não perdem qualidade em nenhum tamanho de tela). A página inicial tem logotipo, banner da promoção, imagens das categorias e uma seção de destaques da semana.

## Linguagens de marcação

**HTML** serve para montar a estrutura das páginas da web (títulos, textos, imagens, links, formulários). É o que usei neste site.

**XML** serve para guardar e transportar dados. Ele não mostra nada na tela, só organiza as informações com tags criadas pelo próprio programador. Exemplo: uma lista de produtos enviada de um sistema para outro.

**Markdown** é uma forma simples de escrever texto formatado usando símbolos, como # para título e - para lista. É usado em arquivos README do GitHub, como este.

## Como abrir

Baixar o projeto e abrir o arquivo index.html no navegador.
